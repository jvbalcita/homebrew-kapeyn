# Homebrew tap for Kapeyn

[Kapeyn](https://github.com/jvbalcita/kapeyn) keeps your Mac awake, intelligently: a menu bar app plus the `kapeyn` command.

```bash
brew install jvbalcita/kapeyn/kapeyn
```

| | |
|---|---|
| Start it | `kapeyn on` (the coffee cup appears in the menu bar) |
| Update | `brew upgrade kapeyn` |
| Uninstall | `brew uninstall kapeyn` |

Kapeyn is built on your Mac from source, so macOS shows no "unverified developer" warning. It needs macOS 12 or later.

The formula is maintained in [jvbalcita/kapeyn](https://github.com/jvbalcita/kapeyn/blob/main/Formula/kapeyn.rb). Each Kapeyn release updates it here automatically, so please open issues and pull requests [there](https://github.com/jvbalcita/kapeyn/issues).
